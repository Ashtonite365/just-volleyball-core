# just-volleyball-core

Unofficial fan-made core / loader for Just Volleyball.

This repository holds the main mod: the runtime loader and the CORE API.

**This is an unofficial fan project.** It is not affiliated with, endorsed by, or supported by the developers of Just Volleyball. Everything published here will be original work. Do not open issues with the official game team about this mod, and do not add game files (the executable, `.pck`, or any extracted official assets) to this repository.

## Status

Core code has not been published yet. This README is currently the only file in the repository.

## Install basics (once a release is published)

1. Close Just Volleyball completely.
2. Back up your existing `mods` folder and `override.cfg`.
3. Use the release zip, hashes, and steps from a published release on this repository. Confirm the file hashes before launching.
4. Keep your own configs and packs: `goofy`, `shots`, `picker.json`, `equipped.json`, `model_settings.json`, and any packs you added yourself.
